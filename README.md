# RMA19

Imágenes del radar del SMN en Santa Rosa, Mendoza (RMA19, SINARAME: https://radares.hidricosargentina.gob.ar/), tal como
salen de su caché, guardadas por la Action `rma19.yml` de la rama `main`. `AAAAMMDD/hhmm.png`: hora de Mendoza.
`vueltas.csv`: qué tramo revisó cada vuelta (una hora sin imagen dentro de un tramo revisado es una que el SMN no dio).
